# 中文说明

本目录提供 ABACUS 所需的数值原子轨道或 SG15 赝势资源。文件名以元素符号开头，结构生成脚本依赖当前目录名和相对路径；这些第三方资源应保持原样。

# DZP orbital resource set

Element-specific ABACUS `*.orb` numerical orbitals, using the same naming convention as the Task II resource set.  Select orbitals by element and keep the files synchronized with the pseudopotential choice.
