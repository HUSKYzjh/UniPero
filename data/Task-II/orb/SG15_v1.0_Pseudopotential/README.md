# English documentation

# SG15 pseudopotential bundle

This directory groups the SG15 v1.0 optimized norm-conserving pseudopotentials used by the Task II ABACUS workflow.  The nested `SG15_ONCV_v1.0_upf/` directory is the path expected by `pos2stru.py`.
